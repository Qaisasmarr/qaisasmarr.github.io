A SHORT INTRO

▸ STUDYING & BUILDING

I'M QAIS.

I'm Qais Alasmar, a computer science student at Concordia University, expecting to graduate in December 2027. I'm interested in software engineering, machine learning, and the decisions that go into a working application.

Adaptive French brings together vocabulary practice, review history, and a recall model. Dijkstra Route Planner takes a graph algorithm and puts it behind an interactive map. The repositories below include the code, setup instructions, and limitations.

At Lava Group, I built a repair-tracking system with Node.js, Express, and MySQL, including SMS updates through Twilio. I also co-founded Unravel and worked with a three-person team on product definition and early prototypes.

ADAPTIVE FRENCH

A Python command-line trainer that logs answers and response times, then schedules vocabulary reviews. It also includes an optional logistic regression model for exploring recall prediction.

The model is experimental; improved retention hasn't been demonstrated.

02 // GRAPH ALGORITHMS
🗺️

DIJKSTRA ROUTE PLANNER

A Java application that uses Dijkstra's algorithm to find routes through a weighted graph. A Swing map shows the selected path; a command-line interface runs the same routing logic.

The map and risk scores are fictional demonstration data.
