# Qais's portfolio

I built it with HTML, CSS, and JavaScript. There’s no framework or build step. Just open `index.html` to run it locally.

The projects section links to my [Adaptive French](https://github.com/Qaisasmarr/adaptive-french) app and [Dijkstra Route Planner](https://github.com/Qaisasmarr/dijkstra-route-planner).
